# NORYXLEN

Bu repository, Termux üzerinde çalışacak olan **NORLOVE / NORYXLEN scripti** içerir.  
Kullanıcı, scripti çalıştırarak isim, renk ve thread belirleyebilir ve ekranda renkli bir şekilde `I LOVE YOU <İSİM>` yazdırabilir.

## Geliştirici
- PANKR_ANK
- NORYXLEN

## Kullanım
1. Termux’ta dosyayı çalıştırın:
```bash
pkg update -y
pkg install git -y
pkg install bash -y
pkg install nano -y
git clone https://github.com/noryxlen-fordrw4/PANKR_.git
cd PANKR_
chmod +x NORYXLEN
./NORYXLEN
-çalışmaz ise
./noryxlen

deneyin
